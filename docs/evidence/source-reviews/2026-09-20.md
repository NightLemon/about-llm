# 2026-09-20 动态来源 LLM 复核

第一次阅读教材的读者请先看[怎样判断教材结论是否可靠](../../reference/accuracy.md)。本页是维护记录，逐项说明本轮 LLM 看到了什么、改了什么，以及仍不能推出什么。

## 复核身份与方法

- 复核日期：2026-09-20（Asia/Hong_Kong）。
- 复核者：OpenAI Codex（GPT-5）；`method=llm`。
- 范围：截至当日有效状态为 `stale` 的 20 个来源，以及原始状态为 `pending-review` 的 `xiaomi-mimo-rl-dashboard`。
- 方法：枚举仓库内全部 `SOURCE:<id>` 标记，打开相应一手页面，把登记范围与标记附近的 claim 逐条对照；再更新必要正文、日期和同一抓取算法得到的 fingerprint。OpenAI 项使用官方 OpenAI Docs 的页面检索与原页内容。
- 判定：`支持` 表示来源仍直接支持登记范围；`改写后支持` 表示发现了版本、入口或表述漂移，正文修正后才可继续使用；无法判断的条目应保留 `pending-review`，本轮没有这类遗留项。

页面可访问和 fingerprint 一致都不是语义结论。本记录没有调用付费 API、安装目标 SDK、运行 GPU/vLLM 服务、重跑供应商 benchmark，也不认证上游训练、账号可用性、价格、许可或生产行为。
