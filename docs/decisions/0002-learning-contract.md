# ADR 0002：教学正文使用学习契约

- 状态：接受
- 日期：2026-08-28

## 背景

读者进入长篇技术页面时，需要快速判断先修、首次阅读路线、完成标准和卡住后的返回点。仅靠统一目录标题无法表达这些入口。

## 决策

`models/`、`foundations/`、`core/`、`training/`、`systems/`、`applications/`、`quality/` 和 `frontier/` 下的教学正文保留一个 `<!-- learning-contract -->`，并包含贡献规范定义的五个字段。页面结构可以随主题调整，不要求批量拆页或机械复制标题。

## 结果

`scripts/check_docs.py` 只执行可确定验证的契约与密度阈值。是否拆页由真实学习路线中的跳转、重复和认知负担决定，不设全站主观 CI 门禁。

## 当前实施说明（2026-09-13）

检查器要求八个指定教学目录的每页恰有一个标记，标记出现在页面前 2,000 个字符内，并在同一契约中找到五个字段。
它还对读者页检查 600 行、45 个小节和 200 字符 prose 行的默认上限；已有债务记录在可读性 baseline 中，实际改善后必须收紧对应预算。

这些是可重复的结构与密度检查，不证明读者理解、路线适合所有先修，或页面的解释已经足够。涉及新的例子、表格、公式或复杂图时，维护者仍应按声明的读者与先修进行语义阅读；AI 阅读记录只能作为启发式审校证据，不能写成真实人类理解率或阅读时长。
