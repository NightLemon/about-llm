# ADR 0002：教学正文使用学习契约

- 状态：接受
- 日期：2026-08-28

## 背景

读者进入长篇技术页面时，需要快速判断先修、首次阅读路线、完成标准和卡住后的返回点。仅靠统一目录标题无法表达这些入口。

## 决策

`models/`、`foundations/`、`core/`、`training/`、`systems/`、`applications/`、`quality/` 和 `frontier/` 下的教学正文保留一个 `<!-- learning-contract -->`，并包含贡献规范定义的五个字段。页面结构可以随主题调整，不要求批量拆页或机械复制标题。

## 结果

`scripts/check_docs.py` 只执行可确定验证的契约与密度阈值。是否拆页由真实学习路线中的跳转、重复和认知负担决定，不设全站主观 CI 门禁。
