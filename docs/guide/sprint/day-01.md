## 动手

最小训练闭环的关键在于：**先预测再运行**。

在运行之前，先写下你的预测：

1. `learning_rate=2.0` 这个值，你觉得会收敛还是发散？为什么？
2. 如果把它改成 `0.001`，loss 曲线的形状会怎么变？
3. batch size 变大两倍，单步 loss 的方差会怎么变？

然后按 [ml-dl.md](../../foundations/ml-dl.md#ml-minimal-loop) 的命令运行，把实际结果与预测对照。
预测错的地方，就是今天真正学到的东西。

## 必答题

不看笔记回答：

1. 一个 `[batch, seq, hidden]` 的张量做 `softmax(dim=-1)`，是在哪个方向上归一化？为什么 LLM 里几乎总是最后一维？
2. 梯度下降为什么要减去梯度而不是加上？
3. 训练时的 loss 下降，为什么不能直接当作"模型变好了"？

第 3 题答不出来就再读一遍 ml-dl 里关于训练集 / 验证集分离的段落——
这是本仓库反复强调的"证据边界"意识的第一次出现。
