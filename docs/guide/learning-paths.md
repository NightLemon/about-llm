# 学习路径

路径不是门槛。遇到不懂的数学时按需回补，不必先修完全部微积分才开始。

## 入门路径：从使用者到理解者

建议 6 周，每周 5–8 小时。

| 周 | 主题 | 可交付成果 |
|---|---|---|
| 1 | Python/张量、机器学习、NLP 基础 | 实现词频与简单分类器；解释训练/验证/测试集 |
| 2 | Tokenization、Embedding、语言建模 | 检查不同文本的 token 数；计算交叉熵和困惑度 |
| 3 | Transformer、位置与注意力 | 手算一次缩放点积注意力；标注各张量形状 |
| 4 | 生成、Prompt、结构化输出 | 比较温度与 top-p；建立 30 条小型评测集 |
| 5 | RAG 与向量检索 | 构建带引用问答；测 Recall@k 和答案忠实度 |
| 6 | 安全、成本与综合项目 | 完成威胁模型、错误分析和项目报告 |

## 工程路径：从原型到生产

建议 8–12 周，有 Python、HTTP、数据库和基本深度学习经验。

1. **模型接口层**：消息协议、流式输出、超时、重试、幂等、结构化输出。
2. **RAG 数据层**：解析、切分、元数据、索引、混合检索、重排、引用。
3. **Agent 执行层**：工具 schema、权限、状态机、循环上限、人工确认。
4. **评测层**：黄金集、LLM-as-judge 校准、成对比较、线上实验和回归门禁。
5. **服务层**：批处理、缓存、限流、KV Cache、量化、GPU 容量规划。
6. **治理层**：PII、提示注入、供应链、审计日志、数据保留和事故响应。

毕业标准：一个不是“演示即成功”的系统——有明确 SLO、版本化评测集、可追踪引用、失败降级、成本仪表盘和红队报告。

## 研究路径：从复现到提出问题

建议先掌握线性代数、概率、优化和 PyTorch。

1. 复现一个小型 decoder-only Transformer，从数据加载到生成全部自己写。
2. 复现一项单变量结果，例如位置编码外推、LoRA 秩或量化位宽的影响。
3. 阅读相互矛盾或结论不同的论文，找出数据、规模、预算和评价协议差异。
4. 写研究问题：假设、可证伪预测、基线、消融、算力预算、风险与停止条件。
5. 预先登记评价指标，报告负结果、方差和限制，避免只展示最好的一次运行。

## 数学补给路径

按需求回补：

- 看不懂张量形状 → 向量、矩阵乘法、转置、广播。
- 看不懂 softmax/损失 → 指数、对数、概率分布、最大似然、交叉熵。
- 看不懂训练 → 导数、链式法则、梯度下降、自动微分。
- 看不懂采样 → 条件概率、熵、KL 散度、重要性采样的直觉。
- 看不懂规模化实验 → 均值方差、置信区间、回归、幂律与实验设计。
