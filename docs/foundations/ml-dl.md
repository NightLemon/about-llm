# 机器学习与深度学习

## 从任务到学习系统

监督学习用样本 \((x,y)\) 学习从输入到标签的映射；自监督学习从数据本身构造标签，例如遮住词再预测或用前文预测后文；强化学习通过动作、环境反馈和累计回报学习策略。LLM 预训练主要是自监督学习，后训练可能混合监督学习、偏好学习和强化学习。

一个完整问题必须明确：

- 数据分布和采样过程；
- 模型族与参数化方式；
- 训练目标和优化方法；
- 评价指标和部署约束；
- 分布变化、失败成本与人工监督。

## 数据划分与泛化

- **训练集**拟合参数。
- **验证集**选模型、阈值和超参数。
- **测试集**只用于最终无偏估计。

数据应按真实使用场景划分。时间序列用时间切分；同一用户、文档的切片或近重复内容不能跨集合，否则会泄漏。LLM 基准还要排查预训练污染。

欠拟合表示模型连训练规律也没学好；过拟合表示记住训练细节却不能泛化。正则化手段包括权重衰减、dropout、数据增强、早停和限制容量，但大模型的双下降、插值与规模规律使经典“小模型直觉”不总能直接外推。

## 神经网络

神经网络交替使用线性变换和非线性激活：

\[
h_{l+1}=\sigma(W_lh_l+b_l)
\]

如果没有非线性，多层线性变换仍等价于一层。现代 Transformer 的 MLP 常用 GELU、SiLU 或门控变体 SwiGLU。残差连接让层学习增量 \(x+F(x)\)，改善深层网络的梯度传播；LayerNorm 或 RMSNorm 稳定不同特征尺度。

## 表示学习与 Embedding

Embedding 把离散 id 映射到连续向量。相似的上下文压力使语义或语法相关项形成几何结构，但“向量某方向对应一个纯概念”并非普遍保证。模型内部表示具有上下文性：同一个 token 在不同句子中的隐藏状态不同。

## 训练循环

```python
for batch in loader:
    optimizer.zero_grad()
    logits = model(batch["input_ids"])
    loss = cross_entropy(logits, batch["labels"])
    loss.backward()
    clip_grad_norm_(model.parameters(), max_norm=1.0)
    optimizer.step()
    scheduler.step()
```

真实 LLM 训练还涉及分布式通信、梯度缩放、激活重计算、检查点、数据恢复和异常监控。

## 评价基础

分类常用准确率、精确率、召回率、F1、ROC-AUC 或 PR-AUC。类别极不平衡时，准确率可能误导。生成任务没有唯一标签，需组合参考答案指标、语义评价、事实验证和人工偏好。

校准关注“置信度是否匹配真实正确率”。语言模型的序列概率受长度、表述和 tokenizer 影响；不要把原始 log probability 当作跨任务通用的置信度。

## 常见误区

- **训练损失下降就代表产品更好**：训练目标只是代理目标，必须在目标分布和业务指标上验证。
- **参数越多必然越好**：数据、训练算力、推理预算、任务和后训练同样关键。
- **Embedding 距离就是事实关系**：它反映训练目标塑造的统计结构，可能带偏见且依赖模型。
- **单次随机种子足够**：小数据或不稳定训练时，方差可能大于方法差异。
