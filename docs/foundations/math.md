# 数学基础

## 学习目标

- 能跟踪 Transformer 中常见张量的形状和运算。
- 理解概率、交叉熵、梯度与优化器在训练中的角色。
- 知道公式的假设和工程含义，不只会套符号。

## 线性代数：模型的计算语言

标量、向量、矩阵、张量分别可看作 0、1、2 和更高维数组。批量文本常表示为

\[
X \in \mathbb{R}^{B\times T\times d}
\]

其中 \(B\) 是 batch size，\(T\) 是序列长度，\(d\) 是隐藏维度。线性层 \(Y=XW+b\)，若 \(W\in\mathbb{R}^{d\times h}\)，则 \(Y\in\mathbb{R}^{B\times T\times h}\)。前两维不参与权重矩阵乘法。

必须熟悉：

- **点积** \(x^Ty\)：同时编码方向相似度和模长；注意力用它计算匹配分数。
- **矩阵乘法**：内维必须相等；先写形状能发现多数实现错误。
- **转置**：交换轴；多头注意力常在 `[B,T,H,D]` 与 `[B,H,T,D]` 间转换。
- **范数**：\(L_1\)、\(L_2\) 衡量大小；用于正则化、梯度裁剪和相似度归一化。
- **特征值/奇异值**：帮助理解低秩近似、LoRA、训练稳定性和权重压缩。

余弦相似度

\[
\cos(x,y)=\frac{x^Ty}{\|x\|_2\|y\|_2}
\]

只比较方向。向量检索中要确认模型是否要求归一化；归一化后点积等于余弦相似度。

## 概率：语言模型输出的含义

随机变量的分布满足 \(p(x)\ge 0\) 且总和为 1。条件概率

\[
p(x\mid y)=\frac{p(x,y)}{p(y)}
\]

语言模型用链式法则把序列概率分解为：

\[
p(x_{1:T})=\prod_{t=1}^{T}p(x_t\mid x_{<t})
\]

这不是说模型独立预测每个 token，而是每一步都以此前上下文为条件。

常用统计量：

- **期望**：重复采样的长期平均。
- **方差**：结果相对均值的波动。
- **最大似然估计**：选择让观测数据概率最大的参数。
- **贝叶斯公式**：用证据更新信念；模型给出的 token 概率通常不能直接解释为某事实为真的可信度。

## 信息论：损失和不确定性

分布 \(p\) 的熵：

\[
H(p)=-\sum_x p(x)\log p(x)
\]

熵越高，分布越不确定。真实分布 \(p\) 与模型分布 \(q\) 的交叉熵：

\[
H(p,q)=-\sum_x p(x)\log q(x)
\]

它满足 \(H(p,q)=H(p)+D_{KL}(p\|q)\)。训练数据固定时，最小化交叉熵等价于减小从真实分布到模型分布的 KL 散度。

单个正确类别 \(y\) 的负对数似然是 \(-\log q(y)\)。若正确 token 的预测概率为 0.8，损失约为 0.223；若为 0.01，损失约为 4.605。错误且自信会受到更大惩罚。

困惑度 \(PPL=\exp(\text{平均 NLL})\)。它可直观理解为每一步面对的“有效候选数”，但只有在相同 tokenization 与数据上才适合比较。

## 微积分与自动微分

导数描述输出对输入的局部变化率。复合函数通过链式法则传播：

\[
\frac{\partial L}{\partial x}=\frac{\partial L}{\partial y}\frac{\partial y}{\partial x}
\]

反向传播不是一种独立于微积分的学习规则，而是高效计算计算图上梯度的方法。训练循环是：前向计算损失 → 反向计算梯度 → 优化器更新参数 → 清空梯度。

## 优化

最基本的梯度下降：

\[
\theta_{t+1}=\theta_t-\eta\nabla_\theta L(\theta_t)
\]

\(\eta\) 是学习率。LLM 常用 AdamW：利用一阶矩与二阶矩的指数移动平均自适应缩放更新，并把权重衰减与梯度更新解耦。

关键工程概念：

- **warmup**：训练初期逐渐提高学习率，缓解随机初始化和不稳定统计造成的巨大更新。
- **衰减计划**：余弦或线性衰减让后期更新更细。
- **梯度裁剪**：限制梯度范数，避免偶发尖峰破坏训练。
- **梯度累积**：多个 micro-batch 累积后更新，模拟更大的全局 batch。
- **混合精度与 loss scaling**：降低显存和算力，同时避免低精度下溢。

## 统计与实验

只比较两个均值不够。至少记录样本量、方差/置信区间、随机种子和多次运行结果。测试集反复用于调参会变成事实上的验证集。多指标、多数据集反复尝试后只报告最好结果，会产生多重比较与选择偏差。

相关不等于因果。要声称某组件带来提升，应尽量使用受控消融：保持数据、训练 token、算力、调参预算和评测协议一致，只改变目标组件。
