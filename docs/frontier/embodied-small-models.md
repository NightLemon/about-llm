# 具身、计算机使用与小模型

## 具身智能

具身 Agent 从传感器观察环境，采取物理动作并获得新观察。与纯文本不同，现实动作有延迟、噪声、不可逆和安全后果。常见组成：视觉/语言感知、状态估计、任务规划、运动规划、低层控制和安全控制器。

Vision-Language-Action 模型把图像、语言和机器人动作联合建模。动作可离散 token 化或预测连续轨迹；训练来自遥操作、机器人日志、仿真和视频。不同机器人形态、相机和控制频率带来 domain shift。

安全不能只靠模型拒答：碰撞检测、力/速度限制、工作空间、急停、人类接管和形式化控制屏障必须在低层独立执行。先仿真与受控场地测试，再逐级扩大。

## GUI 与计算机使用

模型读取截图/可访问性树，执行点击、输入、快捷键或浏览器动作。挑战包括坐标定位、动态页面、弹窗、长任务状态和隐藏恶意内容。优先使用语义 DOM/可访问性节点和受限 API，视觉点击作为补充。

把网页内容视为不可信；登录、付款、删除、发布等需要明确确认。使用隔离浏览器配置、域名 allowlist、下载扫描、凭证代理和动作审计。验证码和反自动化机制不应被绕过。

评价使用任务成功率、步骤效率、恢复、错误副作用和安全违规；在可重置模拟环境测试，避免把真实账户当基准。

## 小语言模型

小模型可定义为能在目标边缘/单卡预算内运行的模型，边界随硬件变化。优势是低延迟、低成本、可本地、易专用；弱点是长尾知识、复杂推理和鲁棒性。

提升方法：

- 高质量/课程数据和更充分 token 训练；
- 从强教师蒸馏 logits、答案或验证过的轨迹；
- 剪枝、量化、低秩与结构化设计；
- RAG、工具和路由弥补参数知识；
- 领域 SFT/adapter，保持通用回放；
- speculative decoding 中作为 draft。

蒸馏可能复制教师偏见和错误，且教师生成数据的许可/来源需审查。

## 模型路由与级联

先用规则/小模型估计任务难度或置信度，简单请求直接处理，困难请求升级大模型。阈值通过风险—覆盖曲线选择；路由错误会把困难/高风险请求交给弱模型。高风险类别可直接固定路由，不靠自报置信。

级联可让小模型先答，大模型审查或只在验证失败时介入。计算期望成本时包括升级率、重复 token 和验证开销。

## 联邦与本地个性化

本地 adapter 或联邦更新可减少原始数据集中上传，但梯度、模型差分和遥测仍可能泄漏。结合安全聚合、差分隐私、设备资格、投毒检测和可撤销个性化。设备异构与离线导致参与偏差。
