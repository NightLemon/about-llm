# 多模态模型

## 目标

多模态模型把文本与图像、音频、视频、文档页面或传感器信号映射到可交互表示，完成理解、生成和跨模态对齐。它不是简单“给 LLM 看像素”：不同模态的采样密度、结构、噪声和评价方式完全不同。

## 视觉语言模型

常见架构：

1. 预训练视觉编码器（ViT 等）把图像切成 patch 并输出视觉 token。
2. 投影器、Q-Former 或 cross-attention 将视觉特征对齐到语言模型空间。
3. LLM 条件生成文本；训练可分视觉-文本对齐、指令微调和偏好优化阶段。

端到端统一模型也可把图像离散为 token，与文本在同一序列建模；生成图像常用离散自回归或扩散/流模型解码器。

### 分辨率与 token

固定缩放会丢小字，原图直接切 patch 又导致 token 暴涨。常见动态分辨率、tiling、缩略图 + 局部块或视觉 token 压缩。图像数量和分辨率会占用上下文与 KV Cache；必须在 OCR、空间细节和成本间权衡。

### 文档理解

文档包含二维布局、文字、表格、图表和阅读顺序。纯 OCR + 文本 LLM 便于检索和引用，但丢视觉关系；原生视觉模型保留布局，却可能在细小字符和精确数字上出错。可靠系统通常组合 OCR、布局解析、视觉模型和规则校验。

## 对齐训练

图文对比学习拉近匹配对、推远不匹配对；captioning 学习图像条件生成；image-text matching 判断配对；多模态指令数据教模型按对话完成定位、OCR、VQA 与推理。网页 alt text 噪声大，人工/合成 caption 可能更详细但引入生成偏差。

## 音频与语音

- ASR：音频 → 文本，常用 CTC、transducer 或 encoder-decoder。
- TTS：文本 → 声学表示/音频，涉及音色、韵律和声码器。
- Speech-to-speech：保留语气与低延迟，可能绕过文本安全检查。
- 音频理解：环境声、音乐、说话人和事件。

音频按时间高频采样，需下采样/分帧。流式系统关注首包延迟、端点检测、打断和回声。声音克隆涉及身份、同意、水印与诈骗风险。

## 视频

视频同时有空间与时间维，token 成本巨大。常见均匀/事件关键帧采样、时空 patch、层次编码和长视频检索。只抽稀帧可能漏掉瞬间事件或顺序；评测要覆盖时间定位、因果顺序、音画同步和全局总结。

## 评测

通用指标之外，检查 OCR 字符/字段准确、对象幻觉、空间关系、计数、图表数值、时间定位、跨模态引用和无障碍描述。题目可能可由文本线索猜中，应做遮蔽/反事实测试确认模型真正使用目标模态。

## 安全

图像内隐藏文字可做提示注入；音频可用超声/噪声攻击；元数据可能泄露位置；模型可能识别人脸或敏感属性。对不同模态分别扫描，限制外部内容的指令权限，并对高风险识别取得合法授权。
