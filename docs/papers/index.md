# 近期论文解读

这个板块把快速变化的研究动态与稳定教材分开。它不追求收录最多论文，而是帮助工程师回答三个问题：论文真正解决了什么、证据支持到哪里、下一步怎样转成可验证的工程问题。

## 怎样选择论文

每期使用固定日期的外部关注信号形成候选，再由编辑按课程相关性补充少量精选：

1. **榜单候选**：记录具体榜单 URL、覆盖周期和快照日期。榜单只解释“为什么现在读”，不证明质量、正确性或长期影响。
2. **编辑精选**：选择与现有课程、可执行项目或重要反例直接相关的新论文，并明确它不来自该期榜单。
3. **原文核查**：标题、版本、日期、方法、数字和限制以论文原文为准；项目页只补 demo、代码或数据入口。
4. **结论降级**：作者报告写成“作者报告”；预印本写成“预印本”；没有独立复现时不写成已确立事实。
5. **版本固定**：解读记录核查版本。后续修订若改变关键实验或限制，更新快照并在变更记录中说明。

热门不等于重要，重要不等于正确。点赞、讨论量、机构知名度、模型规模和漂亮 demo 都不能替代实验设计、基线公平性、消融、成本口径和失败样例。

## 每篇怎样读

首期解读统一使用六个问题：

| 问题 | 要找的证据 |
|---|---|
| 它解决什么 | 可证伪的问题定义，而不是论文标题中的愿景 |
| 方法是什么 | 数据、模型、runtime、harness 与 verifier 各自做什么 |
| 证据是什么 | 数据集、模型、基线、指标、预算、绝对值与方差 |
| 限制在哪里 | 作者限制、版本冲突、内部数据、自动 judge 与缺失消融 |
| 怎样迁移到工程 | 可以加入哪个 schema、测试、观测或发布门禁 |
| 不能推出什么 | 哪些模型、数据、硬件、供应商或生产环境没有被证明 |

建议先读每篇的“为什么值得读”和“先看限制”，再决定是否进入论文正文。第一次阅读不必逐行复现所有公式，但必须能说清比较对象、分母和实验边界。

## 证据层级

- **榜单页面**：只证明该论文在指定快照中被展示和排序。
- **arXiv/会议论文**：证明作者在固定版本中写了什么，不自动证明结果已独立复现。
- **作者项目页或仓库**：补充 artifact 与演示；仍属于作者提供的证据。
- **本仓库复现**：只有实际加入代码、环境、原始输出和失败测试后，才算本地可执行证据。
- **生产证据**：还需要目标数据、硬件、流量、权限、成本和长期运行验证。

## 更新节奏

默认按月或季度新增快照，不静默改写旧期的“当时热门”。维护者应在发布前重新核对来源日期、论文版本和外部链接；来源超过 90 天未复核时，内容准确性门禁会失败。

长期有效的基础论文仍放在[参考资料](../reference/resources.md)，稳定概念回写到相应教材。快照页保留当时的选择依据、争议和版本边界，避免把动态榜单混入永久书目。
