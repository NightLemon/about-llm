# 预训练

## 目标

decoder-only LLM 通过最小化下一个 token 的平均负对数似然训练：

\[
\mathcal{L}(\theta)=-\frac{1}{N}\sum_{i=1}^{N}\sum_t m_{i,t}\log p_\theta(x_{i,t}\mid x_{i,<t})
\]

\(m\) 是 loss mask，用于忽略 padding 或不需要训练的位置。训练用真实前缀并行预测所有位置，推理才逐 token 自回归。

## 开始前的预算

先确定目标参数量、token 数、上下文长度、数据混合、硬件数量、预计利用率、检查点间隔和故障预算。用小规模试验估计吞吐、显存和损失曲线，再外推总时间与成本。保留数据处理、评测和失败重跑的预算。

## 参数初始化与稳定性

权重通常按隐藏维度缩放随机初始化；残差分支可能使用更小初始化。训练早期最脆弱，常配合学习率 warmup、BF16、稳定的归一化、梯度裁剪和 logits/损失监控。

异常信号包括：loss 突刺或 NaN、梯度范数暴涨、激活出现极端值、token 吞吐下降、数据批次重复、某些 GPU 不同步。不能只看全局平均 loss；按数据域、语言、长度分桶能更早发现问题。

## 优化器与调度

常见 AdamW 配置包含学习率、β₁/β₂、epsilon 和 weight decay。bias 与 norm 参数是否衰减依实现。批量增大通常允许提高学习率，但不是无限线性；超大 batch 会降低每 token 更新频率并影响泛化。

学习率多采用 warmup 后余弦/线性衰减，或训练到非零的最终学习率以支持继续训练。应该以 consumed tokens 而非 epoch 描述大规模训练进度，因为混合数据可能没有自然 epoch。

## 上下文课程

短序列训练更便宜，后期扩展长上下文可节约算力，但会改变位置分布与数据打包。需要确认最终模型在目标长度上获得足够 token，并评测检索、聚合、生成一致性，而非只测困惑度。

## 检查点与恢复

完整检查点至少包括模型参数、优化器状态、学习率调度、随机数状态、数据迭代器位置和训练配置。分布式分片策略变化时恢复更复杂。保存前后应校验文件、进行一次加载和前向测试，并周期性保留不可覆盖的里程碑点。

## 评测与停止

持续记录训练/验证 loss、按域 perplexity、下游能力、安全、记忆与偏见指标。下游评测频率要平衡成本。停止不只看 loss：边际能力收益、数据耗尽、预算、过拟合和推理目标都会影响决策。

## 继续预训练

Domain-Adaptive Pretraining 用领域无标注文本继续语言建模。它适合大量专业文本和术语，但可能造成通用能力退化。可混入通用数据、降低学习率、缩短训练、使用参数高效方法，并同时评测领域与通用能力。

扩词表或改变 tokenizer 需要初始化新增 Embedding/输出 head，并训练足够数据；直接替换 tokenizer 会破坏原有 token-id 与权重对应。

## 估算与指标

- **MFU**（Model FLOPs Utilization）：实际用于模型计算的估计 FLOPs / 硬件峰值 FLOPs。
- **tokens/s/GPU**：需同时报告序列长度、精度和模型配置。
- **loss/token**：明确是否包含 padding、不同域如何加权。
- **训练 FLOPs**：注明估算公式而非伪装成实测能耗。
