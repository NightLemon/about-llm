    资料与论文¶

    优先阅读一手资料。这里按概念价值而非“最新榜单”组织；访问日期和版本对快速变化的实现文档尤其重要。

    需要跟进近期研究时，使用独立的近期论文解读和固定日期快照。那里记录“为什么现在读”、原文证据、限制与不可外推项；本页继续维护长期有效的基础书目。

    基础¶

    • Jurafsky & Martin, Speech and Language Processing（在线草稿）：NLP 全景与术语基础。
    • Goodfellow, Bengio & Courville, Deep Learning, 2016：深度学习数学与优化基础。
    • Bishop & Bishop, Deep Learning: Foundations and Concepts, 2024：概率视角的现代教材。
    • Hugging Face, NLP Course：tokenizer、Transformer 与生态实践。

    Transformer 与语言模型¶

    • Vaswani et al., Attention Is All You Need, 2017：Transformer 原始架构。
    • Devlin et al., BERT, 2018：双向 masked LM。
    • Brown et al., Language Models are Few-Shot Learners, 2020：规模与上下文学习。
    • Su et al., RoFormer, 2021：RoPE。
    • Dao et al., FlashAttention, 2022：IO-aware 精确注意力。

    规模、数据与训练¶

    • Kaplan et al., Scaling Laws for Neural Language Models, 2020。
    • Hoffmann et al., Training Compute-Optimal Large Language Models, 2022。
    • Lee et al., Deduplicating Training Data Makes Language Models Better, 2021。
    • Penedo et al., The RefinedWeb Dataset for Falcon LLM, 2023：网页数据流水线案例。
    • Rajbhandari et al., ZeRO, 2019：大模型状态分片。

    后训练¶

    • Ouyang et al., Training language models to follow instructions with human feedback, 2022：InstructGPT/RLHF。
    • Hu et al., LoRA, 2021。
    • Dettmers et al., QLoRA, 2023。
    • Rafailov et al., Direct Preference Optimization, 2023。
    • Bai et al., Constitutional AI, 2022。

    RAG 与 Agent¶

    • Lewis et al., Retrieval-Augmented Generation, 2020。
    • Karpukhin et al., Dense Passage Retrieval, 2020。
    • Nogueira & Cho, Passage Re-ranking with BERT, 2019。
    • Yao et al., ReAct, 2022。
    • Schick et al., Toolformer, 2023。

    持续更新：API 与互操作标准¶

    本节只列需要按版本和访问日期持续复核的官方入口，不把当前产品状态写成永久事实。

    • Model Context Protocol，Introduction、2025-11-25 transport、lifecycle 与 tools：tools/resources/prompts、stdio/HTTP、capability、结构化结果与安全边界。
    • A2A Protocol，Specification、v1.0.0 JSON Schema 与官方 Python SDK：Agent Card、message/task/artifact、JSON-RPC/HTTP+JSON/gRPC binding、长任务与跨 Agent 协作；核对版本与 SDK compatibility，不把单一 loopback control 写成完整 conformance。
    • Google Gemini，Interactions API 与 GenerateContent API：分别核对状态、steps、工具、流式事件与迁移边界。
    • Anthropic，Messages API：核对顶层 system、content blocks、usage 与 stop reason。
    • OpenAI，API documentation：按所用 endpoint、model snapshot 与功能版本核对请求、工具、stream 和 usage。

    协议/产品文档变化快。项目接入时把 URL、访问日期、API/协议版本和 SDK 版本写入 manifest，并用目标账号与网络环境另做 smoke test。

    推理与服务¶

    • Kwon et al., Efficient Memory Management for LLM Serving with PagedAttention, 2023。
    • Leviathan et al., Fast Inference from Transformers via Speculative Decoding, 2022。
    • Frantar et al., GPTQ, 2022。
    • Lin et al., AWQ, 2023。

    评测、解释与安全¶

    • Liang et al., Holistic Evaluation of Language Models, 2022。
    • Srivastava et al., BIG-bench, 2022。
    • Zheng et al., Judging LLM-as-a-Judge, 2023。
    • Bommasani et al., On the Opportunities and Risks of Foundation Models, 2021。
    • Panfilov et al., Stealing Reasoning Traces from Proprietary LLM APIs, 2026：opaque reasoning block 的跨上下文重放、轨迹发布风险与 context-bound envelope；论文注明披露后原攻击截至 2026 年 8 月已不可复现。
    • OWASP, Top 10 for LLM Applications：应用威胁清单；使用时核对当前版本。
    • NIST, AI Risk Management Framework：风险治理框架。
    • Mitchell et al., Model Cards for Model Reporting, 2018。
    • Gebru et al., Datasheets for Datasets, 2018。

    多模态与长序列¶

    • Radford et al., CLIP, 2021。
    • Alayrac et al., Flamingo, 2022。
    • Liu et al., LLaVA, 2023。
    • Beltagy et al., Longformer, 2020。
    • Gu & Dao, Mamba, 2023。

    阅读原则¶

    论文链接只代表值得学习，不代表仓库为其全部结论背书。阅读时核对版本、数据、规模、对照、推理预算与复现；对当下模型/法规/产品信息再查官方最新来源。
