    学习路径¶

    路径不是考试，也不要求一次补齐所有数学。选择最接近当前目标的一条，完成一个可展示的成果后再扩展。

    目标 路线 建议投入
    从零理解 LLM 基础路线 6 周
    构建 RAG 或 Agent 应用工程路线 6–8 周
    学习微调与训练 模型工程路线 6–10 周
    学习推理部署 系统工程路线 6–10 周
    做论文复现 研究路线 按项目

    基础路线¶

    适合第一次系统学习 LLM 的读者。每周约 5–8 小时。

    周 学习内容 可交付成果
    1 机器学习与 NLP 解释训练/验证/测试集，并从 logits 算一次 NLL
    2 Tokenization 比较中英文、数字、代码和 emoji 的 byte/token 差异
    3 Transformer 手算两 token 注意力，标注 Q/K/V/score 形状
    4 生成入门 比较 greedy、temperature 与 top-p 的输出分布
    5 RAG 构建带来源的问答，并区分检索错误与生成错误
    6 评测与安全 完成 30 条样例、错误分类和一个越权负例

    完成标准：能从文本输入一路解释到模型输出，并为一个小任务建立可重复的评价方法。

    应用工程路线¶

    先修：基础路线第 2–6 周，外加 Python、HTTP 和数据库基础。

    1. 定义任务：用 Prompt 写清输入、输出、拒答和结构化字段。
    2. 建立 RAG 基线：完成摄取、检索和引用。
    3. 加入权限与失败处理：在生产 RAG中处理 ACL、索引更新和无答案情况。
    4. 引入 Agent：学习架构与 Runtime，把模型输出视为提议而不是授权。
    5. 建立评测：按评测方法区分任务成功、引用、工具执行和安全指标。
    6. 完成项目：从 RAG Foundations 或 Safe Agent 选择一个项目。

    完成标准：系统对无答案、冲突证据、提示注入、越权请求、工具超时和重复请求都有可测试的行为。

    模型工程路线¶

    先修：基础路线第 1–4 周，熟悉 PyTorch 和基本优化算法。

    1. 数据工程：建立数据 schema、切分、去重和污染检查。
    2. 预训练：理解 token budget、优化器、稳定性和 checkpoint。
    3. 微调总览：先判断问题是否真的需要改权重。
    4. SFT 数据流水线：处理模板、mask、截断和 held-out 数据。
    5. LoRA/QLoRA：建立显存预算、训练基线和 adapter 发布流程。
    6. 偏好对齐：理解偏好数据、DPO/RLHF 和 reward hacking 风险。
    7. 完成 Single-GPU Finetuning 项目中的一个小实验。

    完成标准：报告数据版本、训练预算、曲线、基线、held-out 结果、失败样例和资源消耗；“loss 下降”不能单独作为完成信号。

    系统工程路线¶

    先修：基础路线第 2–4 周，熟悉 Linux、HTTP 和性能测量。

    1. 推理基础：区分 prefill、decode 和 KV Cache。
    2. 推理优化：理解量化、批处理、缓存和内存分配。
    3. vLLM 服务：启动服务并固定模型、请求和采样配置。
    4. 服务与可观测性：测量 TTFT、TPOT、吞吐、排队和错误率。
    5. 硬件与端侧：用算力、带宽和容量账本解释瓶颈。
    6. 完成 Inference Serving 项目的一次压测与故障实验。

    完成标准：能说明负载模型、计时边界、资源上限和失败恢复；不使用单次延迟或平均值代表容量。

    研究路线¶

    研究路线从问题开始，不从“复现一个热门模型”开始。

    1. 写出一个可证伪假设和最小实验。
    2. 固定数据、模型、训练预算、评价代码和随机种子。
    3. 设置简单基线、目标方法和至少一项关键消融。
    4. 运行多个 seed，报告原始结果、差异和失败情况。
    5. 解释证据只支持哪一层结论，并提出最可能推翻它的下一项实验。

    可从近期论文、规模化、可解释性或前沿主题选题。

    完成标准：别人能够根据你的记录重做实验，并得到相同方向的结论；负结果也必须保留。

    数学按需补给¶

    • 看不懂矩阵和广播：读数学基础的线性代数部分。
    • 看不懂 softmax、交叉熵或 KL：读概率与信息论部分。
    • 看不懂反向传播：读链式法则与自动微分，再回到预训练。
    • 看不懂显著性和置信区间：读统计与实验设计，再回到评测方法。

    每个阶段怎样验收¶

    无论选择哪条路线，都保留四样东西：

    1. 一个能运行的最小基线；
    2. 一个主动制造的失败案例；
    3. 一组事先定义的评价标准；
    4. 一段用自己的话写出的结果解释。

    下一步：查看知识地图确认先修，或直接从项目索引选择与路线匹配的成果。
